# LevelEditor

## 概要

LevelEditorは、Blenderで作成したレベルデータをゲームエンジン対応のJSON形式で出力するBlender Addonです。

## 配置理由

このツールをエンジンリポジトリに配置している理由は以下の通りです：

- **エンジンの一部としての開発**: レベルエディターはエンジンシステムの統合コンポーネントとして設計・開発されている
- **エンジン変更への同期対応**: エンジンの仕様変更時に、レベルエディターも同時に更新することで整合性を保持

## 機能

- Blenderシーンからのレベルデータエクスポート
- エンジン仕様に準拠したJSON形式での出力

## 今後の実装予定

- **既存モデル選択機能**: エンジンの既存モデルをBlenderEditor画面で選択・適用
- **カメラワーク編集**: ゲーム内カメラの動作パターンを視覚的に編集
- **当たり判定ライブラリ連携**: 物理エンジンとの統合による衝突判定の設定
- **EnemyのSpawnPoint設置**: 敵キャラクターの出現位置をレベル内に配置
