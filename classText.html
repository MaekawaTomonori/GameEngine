詳解

テキスト描画オブジェクト

文字列・位置・サイズ・色を保持し、Draw() を呼ぶとその フレームの描画キューへ追加される。

使い方

// クラスメンバーとして宣言
Text label_;
// 初期化（一度だけ）
label_.Initialize("Score: 0", 20.f, 20.f, 32.f);
// 毎フレーム Draw() を呼ぶ
label_.SetText("Score: " + std::to_string(score_));
label_.Draw();
